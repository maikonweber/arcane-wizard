# Arcane Wizard

Beat 'em up 2.5D de fantasia sombria. Título no GDD: **Estrutura**. Dois magos caçadores recuperam relíquias, trocam escolas no combo e impedem a invocação de Malakar.

## Status

Pré-produção. Spec: [PRJ-13](../Ecosystem/projects/13-arcane-wizard.md). Fonte: `docs/GDD_Estrutura_Completo_Godot4.docx` v1.0.

## Como abrir

Godot **4.7**. Cena atual: `scenes/main.tscn` (boot / título). O combate começa no backlog P0.

```text
Godot --path "ArcaneWizard"
Godot --path "ArcaneWizard" --editor
```
