# Decisões pendentes

O GDD v1.0 deixa estas escolhas abertas. Não travar arte final, IDs de loja ou coop até o dono marcar.

| Tema | Pergunta | Precisa estar resolvido |
| --- | --- | --- |
| Nome de produto | Título canônico é **Estrutura** (GDD) ou **Arcane Wizard** (pasta)? | Ícone, executável, launcher. |
| Plataformas | PC só, ou também console? Hardware mínimo? | Viewport, qualidade, store. |
| Cooperativo | Local, online ou ambos após o MVP? | Só depois do vertical slice. |
| Modelo comercial | Premium, demo ou acesso antecipado? | Build de loja. |
| Direção visual | 2.5D com modelos 3D (premissa técnica) ou sprites 2D? | Pipeline de assets M0. |
| Violência e tom | Nível de gore, classificação, quão sombria é a narrativa. | Arte de hit e copy 12+. |
| Habilidades por escola | Quantas ativas além de rápida + técnica na 1.0? | Scope de VFX. |
| Quatro escolas do MVP | Premissa: Fogo, Água, Terra, Vento. Confirmar. | M3. |
| Ordem das fases MVP | Premissa: Vila → Cidade → Fortaleza. Floresta no 1.0. | Produção de cenário. |
| Relíquia da Fortaleza | Coroa (terra) vs Olho (raio) vs tema de Volkar (vento/raio). | Narrativa da fase. |
| Seraph | Miniboss do Templo ou chefe de fase própria? | Mapa 1.0. |
| Guardião Silvestre | Mecânica de chefe ausente no GDD. | Antes da arte da Floresta. |
| Doran | Infiltrado na Ordem **ou** corrompido por relíquia? | Roteiro 1.0. |
| Inimigos 11–12 | Dois tipos regionais sem nome no GDD. | Catálogo 1.0. |
| Integração MutterGames | Soft currency, login, launcher neste MVP? | Adapter; padrão do ecossistema é depois do slice. |
| Owner | Quem fecha design e engenharia? | Backlog. |
