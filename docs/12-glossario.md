# Glossário

| Termo | Definição |
| --- | --- |
| Estrutura | Prisão arcana feita das oito relíquias; também título de produto no GDD. |
| Arcane Wizard | Nome da pasta / projeto no monorepo. |
| Escola | Conjunto de poderes e afinidades de um elemento. |
| Status | Condição persistente num ator. |
| Reação | Efeito da combinação **ordenada** de elementos/status. |
| Postura | Resistência a interrupção; zero abre o alvo. |
| Convergência | Estado especial que amplia troca e combina escolas (especial de Kael / medidor cheio). |
| Cancelamento | Interrupção autorizada de uma ação para iniciar outra. |
| Hit-stop | Pausa muito curta para reforçar impacto. |
| Véu | Barreira entre o mundo humano e o Abismo. |
| Relíquia / selo | Um dos oito fragmentos da essência de Malakar. |
| Crawler | Criatura do Abismo que atravessa falhas na Estrutura. |
| Ordem do Eclipse | Organização que quer libertar e controlar Malakar. |
| Guardiões Arcanos | Magos caçadores responsáveis pelas relíquias. |
| Essência | Moeda de atributo. |
| Núcleo Elemental | Moeda que desbloqueia técnicas. |
| Fragmento do Coração | Item de avanço de campanha. |
| Medidor Arcano | Recurso de especial, preenchido por variedade e reações. |
| Loadout | Até quatro escolas equipadas. |
| EncounterDirector | Sistema que spawna e limita ondas numa arena. |
| DamagePacket | Dados de um hit (poder, tags, origem, escola). |
